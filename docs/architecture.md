# SigReactor Architecture

## Project Title

SigReactor – A Signal-Driven Event Framework

## Objective

SigReactor is a lightweight event framework designed to handle
Unix signals and process events in a safe and organized manner.

## Architecture

The system consists of three main modules:

1. Signal Handler
2. Event Manager
3. Reactor

## Working Flow

Signal
   ↓
Signal Handler
   ↓
Event
   ↓
Reactor
   ↓
Event Processing

## Modules

### Signal Handler

Captures Unix signals such as SIGINT and SIGTERM.

### Event

Represents an event generated by a signal or process activity.

### Reactor

Receives events and dispatches them to the appropriate handler.

### Main

Initializes the reactor and starts the event loop.
